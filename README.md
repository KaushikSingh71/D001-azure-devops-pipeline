# 🚀 D001 - Production Ready Azure DevOps CI/CD Pipeline

> A production-style Azure DevOps project demonstrating a complete CI/CD pipeline using Azure DevOps, Docker, Terraform, Azure Container Registry (ACR), and Azure Kubernetes Service (AKS).

---

## 📖 Project Overview

This repository demonstrates how a modern production application can be built, containerized, and deployed automatically using Azure DevOps.

The project follows real-world DevOps practices including Infrastructure as Code (Terraform), containerization (Docker), Continuous Integration & Continuous Deployment (CI/CD), and Kubernetes orchestration.

This repository is being developed step-by-step as part of my Azure DevOps Portfolio.

---

# 🎯 Project Objectives

- Build a production-ready CI/CD pipeline
- Automate application deployment
- Provision infrastructure using Terraform
- Deploy applications to Azure Kubernetes Service (AKS)
- Follow DevOps best practices
- Create a reusable Azure DevOps project for learning and demonstration

# 🚀 Planned CI/CD Flow

1. Developer pushes code to GitHub
2. Azure DevOps Pipeline is triggered
3. Application is built
4. Docker image is created
5. Image is pushed to Azure Container Registry
6. Infrastructure validation is performed
7. Application is deployed to AKS
8. Health checks are executed
9. Deployment is completed successfully
